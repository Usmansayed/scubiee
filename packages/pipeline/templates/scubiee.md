# Scubiee GATE - when to use

Policy only; tool how-to is in Scubiee MCP server instructions.

- **GATE 0** - Not managed (no `scubiee init`). BAN Scubiee MCP locate tools (`map`, `focus`, `grep`, `glob`, `workspace`). USE native Grep/Glob/Read/codebase-search only. Run `scubiee init .` to enroll.
- **GATE 1:ce_*** (managed): task+seed → prefer pack_context (heatmap+hot bodies, one call) or map_context guide; descriptive query; expand_context if thin. No-seed → map/pinpoint/plate. Exact/name/path → host Grep/Glob/Read. Native OK if MCP down/blocked/paused/errors. Edit/Write/Shell stay native. How-to → MCP server instructions.
- **GATE p** - Scubiee STOPPED (`scubiee stop`). BAN all Scubiee MCP tools (map, focus, pinpoint, plate, grep, glob, workspace, expand, search, read, files, recall, neighbors, graph, outline, status loops). USE native Read/Grep/Glob/codebase-search only. Run `scubiee resume` (NOT `init`).

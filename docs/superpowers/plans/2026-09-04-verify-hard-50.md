# Verify-hard: 50 tough tests (related-code heavy)



**Why the old 20/20 board was not believable:** oracle seeds, many seed-only

musts, and must_not far outside the faction firewall.



**This board:** `fixtures/trace-lab/verify_hard.json` — **50** cases, **50**

families. Must sizes min/median/max = **3 / 5 / 11**. Fixture expanded to ~76

nodes (checkout, oauth, webhooks, search, uploads, flags, audit, …).



**Correctness:** `must ⊆ hot` AND `hot ∩ must_not = ∅` (explicit missing /

forbidden per case). No tracer tuning after seeing scores.

Failure modes that show up repeatedly:



- **Precision traps** — same seed, narrow must; tracer over-collects pay/ship/log

- **Upward / mid-graph seeds** — decode, http.get, fetch_docs, verify_sig

- **On-path must_not** — log/track/TOKEN_TTL siblings on auth/job paths

- **Shared hubs** — http.get used by pay, notify, search, flags

- **Multi-reader refs** — TOKEN_TTL in jwt + webhook sig

- **Adversarial wording** — “authentication” in pay/checkout/jobs prompts

## Critical GPU fix (dual AMD Vulkan)

This laptop registers **two** AMD Vulkan ICDs (iGPU + RX 6500M). llama.cpp / Ollama `--list-devices` then crashes with `0xC0000005` and falls back to CPU. The “AMD driver is too old” ROCm warning is a red herring on this card.

**Fix:** pin a single ICD and disable switchable-graphics layers:

```powershell
$env:VK_ICD_FILENAMES = "C:\Windows\System32\DriverStore\FileRepository\u0403196.inf_amd64_d0c41aa30f8bcfb2\B402774\amd-vulkan64.json"
$env:VK_LOADER_LAYERS_DISABLE = "*"
$env:DISABLE_LAYER_AMD_SWITCHABLE_GRAPHICS_1 = "1"
$env:OLLAMA_VULKAN = "1"
```

Also remove/rename Ollama’s bundled loader if present:

`%LOCALAPPDATA%\Programs\Ollama\lib\ollama\vulkan\vulkan-1.dll` → `.bundled`

Confirm: `ollama ps` shows **GPU**, not `100% CPU`.

## Note on “DML”

- **CodeRank embeds:** DirectML (`DmlExecutionProvider`) — already working.
- **Ollama / llama.cpp LLMs on AMD Windows:** **Vulkan**, not DirectML.
- True DML LLM path would be `onnxruntime-genai-directml` INT4 ONNX; model builder currently fails in this conda env (`numpy` metadata / transformers version check). Prefer Vulkan Q4 for speed; revisit Olive/ORT GenAI later for training stack alignment.

## Optional: newer Adrenalin

Driver dates are ~May 2024. Updating Adrenalin is still healthy, but **not required** for ≥100 tok/s once the ICD pin is applied.
